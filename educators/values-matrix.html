Values conflict matrix

Last updated on 17 May 2026

The cases in this matrix are real situations from academic research and student learning contexts. Each case describes a genuine dilemma where multiple values matter but pull in different directions. They represent moments when different values come into tension.

Because these are real cases, each one includes a real outcome: something had to happen in practice. That outcome should not be read as the only correct solution. In many cases, other responses could also have been ethically defensible. Use these cases to examine what is happening, compare possible options, and explore grey areas, not to teach fixed rules or predict guaranteed consequences.

Each case is structured the same way:

1. A situation (~75 words): A realistic scenario that fits on a slide. Personal enough to make it relatable and specific enough to provide room for discussion.

2. Three guiding questions:

  • What values are relevant? Which values matter in this situation?
  • Which values are at conflict? And how? What is the dilemma here? How does one value conflict with another?
  • What would you do next? How do you think this dilemma should be resolved?

How to use them: Work through one question at a time. Think through your own answer first, then reveal what the case shows. Use the outcome as one real example to discuss alternatives, trade-offs, and grey areas, rather than as a fixed rule or guaranteed consequence.
